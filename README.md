# Melhorias Implementadas

## Sistema de Pesquisa

O sistema foi aprimorado para permitir diferentes formas de busca, além da pesquisa por título.

### Funcionalidades:

* Pesquisa por título
* Pesquisa por autor
* Pesquisa por intervalo de anos
* Pesquisa por número de páginas

---

## Sistema de Ordenação

Foi adicionado um menu de ordenação para organizar os livros conforme diferentes critérios.

### Opções:

* Ordenar por título
* Ordenar por autor
* Ordenar por ano (crescente)
* Ordenar por ano (decrescente)
